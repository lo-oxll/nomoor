# نمور — لوحة التتبع

تطبيق PWA يعمل دون إنترنت لتتبع الأنشطة والزيارات والديون. البيانات محفوظة على الجهاز فقط (`localStorage`).

## الهيكل
- `index.html` — الواجهة
- `js/core.js` — الحالة، الإعدادات، التنقل، المشاركة، النسخ الاحتياطي
- `js/lists.js` — القوائم والزيارات والوقت
- `js/activities.js` — الأنشطة والأهداف والإحصائيات
- `js/ledger.js` — الدفتر (ديون، مولدة، جمعية)
- `js/home.js` — الرئيسية، القوالب العراقية، الإعدادات
- `sw.js`, `manifest.json` — PWA (غيّر رقم الإصدار في `sw.js` عند كل تحديث)
- `vendor/` — مكتبات محلية (SheetJS، Font Awesome)

## تعديل التصميم
```
npm install
npm run build:css
```
يُولَّد `css/app.css` من `src/input.css` (Tailwind). ارفع الملف الناتج مع التعديل.
